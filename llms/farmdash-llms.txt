# FarmDash live agent contracts

This directory entry links to the current first-party contracts instead of caching a narrative snapshot.

- Live status and feature availability: https://www.farmdash.one/api/v1/agent/status
- Current fees and tier limits: https://www.farmdash.one/api/v1/fees.json
- Canonical OpenAPI: https://www.farmdash.one/agents/openapi.yaml
- MCP manifest: https://www.farmdash.one/.well-known/mcp.json
- Full agent overview: https://www.farmdash.one/llms.txt
- Public stdio MCP source: https://github.com/Parmasanandgarlic/farmdash-openclaw-skills/tree/main/mcp-server

The MCP server is a local stdio source install; no hosted remote MCP endpoint or published npm package is claimed. A2A transport is not exposed. The OpenAPI split files in this directory are discovery derivatives, not replacements for the live contract.
